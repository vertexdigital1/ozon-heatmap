# 🔥 Ozon Heatmap — когда покупают на Ozon

Интерактивное веб-приложение для визуализации того, **в какие дни недели и часы покупатели чаще всего оформляют заказы** на Ozon.

Работает целиком в браузере: загружаешь CSV-выгрузку заказов из Ozon Seller → получаешь тепловую карту. Данные никуда не отправляются.

**🌐 Открыть приложение:** https://vertexdigital1.github.io/ozon-heatmap/

---

## Что показывает

Приложение строит **heatmap (тепловую карту)**, где:

- **по вертикали** — дни недели (Пн–Вс)
- **по горизонтали** — часы суток (0–23)
- **цвет клетки** — сколько заказов в этот час в этот день

Две вкладки:

| Вкладка | Что показывает |
|---|---|
| **Среднее число заказов** | Сколько в среднем заказов приходится на этот час в этот день недели (с учётом того, сколько раз день недели встречался в данных) |
| **Доля от дня, %** | Какой процент дневных заказов приходится на конкретный час — профиль дня |

Плюс под картой выводится **пик продаж**: самый горячий час самой горячей недели.

---

## Как пользоваться

1. Открой [ссылку](https://vertexdigital1.github.io/ozon-heatmap/).
2. Подожди 5–15 секунд — при первом запуске браузер разворачивает Python-среду.
3. Перетащи в поле загрузки **CSV-выгрузку заказов из Ozon Seller**.
4. Подбери **часовой пояс**  - тут лучше уточнить в поддержке ибо я помню, что в отчете время не МСК а время сервера + 3 часа.
5. Смотри heatmap.
6. При необходимости скачай таблицу кнопкой **«Скачать таблицу (CSV)»**.

**Ничего устанавливать не нужно.** Работает в Chrome, Firefox, Edge, Safari, в том числе на телефоне.

## Откуда взять CSV

В личном кабинете Ozon Seller:

**Аналитика->Моя аналитика->Отчёты**

Нужен отчёт с колонкой **`Принят в обработку`** — по ней строится вся визуализация. Остальные колонки опциональны, но полезны:

- `Статус` — для фильтра отменённых заказов
- `Выкупы товара` — для фильтра «только выкупы»
- `Номер заказа` — по нему считается количество заказов
- `Артикул` — если захочешь смотреть heatmap по конкретному товару

Приложение само определяет разделитель (`;`, `,`, таб) и кодировку (`utf-8`, `cp1251`) — подготовка файла не требуется.

## Часовой пояс — важный момент

Еще раз: Ozon в выгрузках отдаёт время не в московском поясе. Часто это **UTC** или время сервера. 

Поэтому в сайдбаре есть **ползунок сдвига часового пояса**. Подбери его так, как скажут в поддержке, чтобы:

- ночью (2–6) был **провал**
- вечером (19–22) был **пик**
- в выходные был широкий «дневной» профиль

Для большинства выгрузок Ozon подходит **сдвиг +3 часа** (дефолт).

## Как это работает

- **Streamlit** — фреймворк для интерактивных приложений на Python.
- **stlite** — компилирует Streamlit-приложение в один HTML-файл, который запускает Python прямо в браузере через WebAssembly (Pyodide).
- **pandas** — обработка CSV и агрегация по дням/часам.
- **matplotlib** — отрисовка heatmap (без seaborn — он в браузере не работает).

**Приватность:** CSV-файл, который ты загружаешь, **никуда не отправляется**. Он обрабатывается в твоём же браузере. GitHub Pages отдаёт только статичную HTML-страницу.
